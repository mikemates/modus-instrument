# Logos

The official Modus Create logo, as supplied. Single-ink artwork: no gradients, no live text.

| File | What | Ink | Use on |
| --- | --- | --- | --- |
| `MC_Black.svg` | Wordmark — glyph + MODUS CREATE | Black #000000 | Paper and other light grounds |
| `MC_White.svg` | Wordmark | White #FFFFFF | Ink, violet blocks and other dark grounds |
| `MC_Icon_Black.svg` | Glyph alone | Black #000000 | Light grounds, tight spaces, favicons |
| `MC_Icon_White.svg` | Glyph alone | White #FFFFFF | Dark grounds, tight spaces, favicons |

- In code, use the `Logo` component instead of these files: it draws the same artwork in `color-logo` and switches with the theme.
- Never recolour, redraw, stretch or add effects. Size by height.
- Clear space and minimum size: to confirm against the Modus Create brand guidelines.
